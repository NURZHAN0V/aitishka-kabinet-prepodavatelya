# Контекст

Клиент **«Кабинет преподавателя»** — часть экосистемы IT Camp Sochi (школа при Гимназии №16).

Преподаватели работают со своими группами и предметами: журнал, оценки, ДЗ, экзамены, отзывы, рейтинг.

Студенты и родители видят результаты в **электронном дневнике**. Учебная часть управляет расписанием и аккаунтами через **панель учебной части**.
